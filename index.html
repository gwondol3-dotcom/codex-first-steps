연수 안내

오늘 할 일

프로그래밍 언어를 배우지 않습니다. Codex에게 원하는 프로그램을 우리말로 설명하고, 만들어진 프로그램을 직접 실행하면서 고쳐 나갑니다. 아래 복사 버튼을 누르면 프롬프트가 복사되니 Codex 입력창에 붙여 넣으세요.

연수가 끝나면 이런 일을 할 수 있습니다
  1. 자연어로 프로그램 제작을 요청할 수 있다.
  2. Codex가 만든 프로그램을 직접 실행할 수 있다.
  3. 실행 결과를 보고 수정 요청을 할 수 있다.
  4. 기존 프로그램에 새로운 기능을 추가할 수 있다.
  5. 학교 업무와 수업에 활용할 간단한 도구를 직접 만들 수 있다.

설치 및 실습 준비

위에서부터 순서대로 진행하세요. 1~5단계는 꼭 필요하고, 6단계는 선택입니다. 이미 끝낸 단계는 체크만 하고 넘어가면 됩니다.

STEP 1

ChatGPT 계정 준비하기

Codex는 ChatGPT 계정으로 로그인해서 씁니다. Plus 이상 구독이어야 원활하게 사용할 수 있습니다. 이미 ChatGPT를 쓰고 있다면 같은 계정을 그대로 씁니다.

  1. chatgpt.com에 접속해 로그인합니다.
  2. 왼쪽 아래 내 이름(프로필)을 누릅니다.
  3. 현재 요금제(Plus / Pro / Business 등)를 확인합니다.
  4. 비밀번호를 미리 확인해 둡니다.
ChatGPT 열기 chatgpt.com
STEP 2

크롬 브라우저 설치하기

Codex가 만든 HTML 프로그램(타이머, 퀴즈, 설문 분석)을 실행할 때 씁니다. 이미 설치되어 있다면 건너뜁니다. 기본 브라우저로 설정해 두면 HTML 파일을 더블클릭했을 때 바로 크롬으로 열립니다.

  1. 아래 링크에 접속해 [Chrome 다운로드]를 누릅니다.
  2. 내려받은 설치 파일을 실행합니다.
  3. 설치가 끝나면 크롬이 자동으로 열립니다.
Chrome 다운로드 google.com/chrome
STEP 3

Codex 데스크탑 앱 설치하기

오늘 연수는 Codex 데스크탑 앱으로 진행합니다. 폴더를 열고 대화하면 Codex가 파일을 직접 만들고 고쳐 줍니다. 앱을 설치하면 터미널용 codex 명령도 함께 설치됩니다.

  1. chatgpt.com/codex에 접속합니다.
  2. Windows용 앱 다운로드 버튼을 누릅니다. Microsoft Store로 연결될 수 있습니다.
  3. [설치] 또는 [받기]를 누릅니다.
  4. 시작 메뉴에서 Codex를 실행합니다.
Codex 다운로드 chatgpt.com/codex

Codex 입력창에 붙여넣기

다음 기능이 필요해.

1. 학생 이름을 여러 명 입력할 수 있다.

6. '모둠 만들기' 기능을 추가해서 2명, 3명, 4명 단위로 랜덤 모둠을 만들 수 있다.
